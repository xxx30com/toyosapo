# サイト表示確認（ローカルサーバープレビュー）

このプロジェクトは静的HTMLサイト（GitHub Pages公開）。表示確認は必ずローカルサーバー経由で行うこと。

## 手順

1. `mcp__Claude_Browser__preview_start` を `name: "static-site"` で呼ぶ（設定は `.claude/launch.json`、ポート3000）。起動済みなら再利用される。
2. 確認対象のページへ移動する: `http://localhost:3000/<ページ名>.html`（トップは `/index.html`）。直近の会話で変更したページを優先して確認する。
3. スクリーンショットで確認する:
   - そのまま撮るとプレビューパネル幅（約730px）＝**スマホ表示**になる
   - PC表示は `resize_window` で width 1280 を指定してから撮る
   - 両方確認するのが基本
4. 画像切れがないか確認する。疑わしい場合は `read_console_messages`（onlyErrors）や JS で `document.images` の読み込み状態をチェックする。
5. 結果をスクリーンショット付きで報告し、ユーザー自身にも http://localhost:3000 で見られることを伝える。

## 注意

- **file:// で直接開かないこと**。新規追加した画像が読み込まれない既知の問題がある（CSSは読めるので一見正常に見えるが画像が壊れる）。必ずローカルサーバー経由で確認する。
- サーバーはユーザーのPC内のみで動く。外部公開はされない。
- 確認が終わってもサーバーは止めなくてよい（ユーザーが引き続き目視確認するため）。
